# Anexo T.2. Instrumentos de medición y hoja de observación

Todos los formularios se imprimen y se tienen en línea. Se identifican con el código ACU-xx, nunca con el nombre.

## 1. SUS, escala de usabilidad del sistema (10 ítems)
Fuente: Brooke (1996) `\citep{brooke_sus_1996}`; interpretación y bandas en `\citep{bangor_empirical_2008, brooke_sus_2013}`. En el ítem 8 se usa "incómodo" (en inglés *awkward*, no *cumbersome*), según `\citep{lewis_factor_2009}`.
Versión en español: traducción propia del equipo, no una versión validada. `[VERIF]` si se adopta una versión validada, por ejemplo la de Sevilla-González et al., *JMIR Human Factors* 2020, y agregarla al .bib (no está en `tukit.bib`).
Escala: 1 = totalmente en desacuerdo, 2, 3, 4, 5 = totalmente de acuerdo. "El sistema" se lee como "Tukit".

| # | Ítem |
|---|---|
| 1 | Creo que me gustaría usar este sistema con frecuencia. |
| 2 | Encontré el sistema innecesariamente complejo. |
| 3 | Pensé que el sistema era fácil de usar. |
| 4 | Creo que necesitaría el apoyo de una persona técnica para poder usar este sistema. |
| 5 | Encontré que las diversas funciones del sistema estaban bien integradas. |
| 6 | Pensé que había demasiada inconsistencia en este sistema. |
| 7 | Imagino que la mayoría de las personas aprendería a usar este sistema muy rápido. |
| 8 | Encontré el sistema muy incómodo de usar. |
| 9 | Me sentí muy seguro/a usando el sistema. |
| 10 | Necesité aprender muchas cosas antes de poder empezar a usar este sistema. |

Puntaje: ítems impares, respuesta − 1; ítems pares, 5 − respuesta; sumar y multiplicar por 2,5 (rango 0-100). Si falta un ítem, la sesión se marca incompleta para SUS y no se imputa. Umbral de éxito: media ≥ 68 `[VERIF]` fuente primaria del 68 (se atribuye a Sauro; no está en el .bib).

## 2. NPS (intención de recomendación)
Fuente: `\citep{reichheld_one_2003}`. "En una escala de 0 a 10, ¿qué tan probable es que recomiende Tukit a otro acudiente del colegio?" (0 = nada probable, 10 = muy probable). Y: "¿Cuál es la razón principal de su respuesta?"
Promotores 9-10, pasivos 7-8, detractores 0-6. NPS = % promotores − % detractores. Éxito: NPS > 0, con intervalo bootstrap.

## 3. NASA-TLX, versión "raw" (RTLX), seis escalas
Fuente: Hart y Staveland (1988); revisión de Hart (2006). **No están en `tukit.bib`**: `[VERIF]` agregar las dos referencias antes de citar. Marco de carga cognitiva: `\citep{sweller_cognitive_2011}`. La traducción de las escalas es propia. `[VERIF]` si se usa la versión oficial en español de la NASA.
Cada escala se marca en una línea de 21 casillas (0 = muy bajo, 100 = muy alto; en Desempeño, 0 = perfecto, 100 = fracaso).

| Escala | Pregunta |
|---|---|
| Exigencia mental | ¿Cuánta actividad mental y de percepción exigió (pensar, decidir, comparar, recordar)? |
| Exigencia física | ¿Cuánta actividad física exigió (tocar, desplazarse, escribir)? |
| Exigencia temporal | ¿Cuánta presión sintió por el ritmo o el tiempo disponible? |
| Desempeño | ¿Qué tan exitoso/a cree que fue en lograr lo que se le pidió? |
| Esfuerzo | ¿Cuánto tuvo que esforzarse (mental y físicamente) para llegar a su nivel de resultado? |
| Frustración | ¿Qué tan inseguro/a, desanimado/a, irritado/a o estresado/a se sintió, frente a tranquilo/a y satisfecho/a? |

Puntaje: promedio de las seis escalas (sin ponderar). Se aplica dos veces: (a) **retrospectivo**, referido a la última compra de útiles del hogar con su proceso habitual ("piense en la última vez que compró los útiles..."); (b) tras las tareas con Tukit. Límite declarado: sesgo de recuerdo y de novedad.

## 4. SEQ por tarea
Fuente: Sauro y Dumas (2009) `[VERIF]` no está en el .bib. Después de cada tarea: "En general, esta tarea fue:" 1 (muy difícil) a 7 (muy fácil). Se entrega al final de las siete tareas, una línea por tarea, para no interrumpir el pensamiento en voz alta.

## 5. Confianza en la elección (opcional)
"¿Qué tan seguro/a está de que el kit elegido es el adecuado para su hijo/a?" 1 (nada seguro/a) a 7 (muy seguro/a). Se pregunta tras T4.

## 6. Preguntas previas (mínimas, sin datos del hijo)
1. Rol: madre / padre / otro acudiente.  2. Nivel escolar del hijo que usará la prueba: preescolar / primaria / bachillerato.
3. Hijos en el colegio: 1 / 2 / 3 o más.  4. Dispositivo que más usa para compras en línea: celular / computador / tableta.
5. Frecuencia de compras en línea: nunca / alguna vez al año / cada mes / cada semana.
6. Última compra de útiles: ¿dónde (tienda física, en línea, ambas), cuándo y cuánto tiempo le tomó, aproximado?
7. Gasto anual aproximado por hijo en útiles: menos de $700.000 / $700.000 a $1.000.000 / más de $1.000.000 (para las cuotas).
8. ¿Ha reclamado alguna vez al colegio por la lista? Sí / No. 9. ¿Respondió la encuesta anterior de Tukit? Sí / No / No sé. (Lo anota el equipo si lo sabe.)
No se pregunta edad, estrato, ingresos ni nivel educativo.

## 7. Hoja de observación (una por participante, la llena el observador)
Encabezado: ACU-xx, fecha, ronda/etapa, versión del prototipo, moderador, observador, audio (sí/no).

| Tarea | Inicio | Fin | Resultado (S/A/F) | Códigos de error | Citas textuales | Severidad (0-4) |
|---|---|---|---|---|---|---|
| T1-T7 | mm:ss | mm:ss | | | | |

Resultado: **S** sin ayuda; **A** asistida (hubo pista tras 90 s); **F** fallida o abandonada, o tiempo máximo agotado.
Códigos de error: **E1** no encuentra dónde ir; **E2** error al diligenciar un campo; **E3** malinterpreta un texto, rótulo o precio; **E4** acción equivocada para su meta; **E5** omite un paso; **E6** falla o lentitud del sistema (no cuenta contra el participante); **E7** duda larga (más de 10 s) sin acción.
Severidad por problema (0-4): 0 no es problema; 1 cosmético; 2 menor; 3 mayor (impide o retrasa la meta); 4 catastrófico (hace perder la tarea). Se asigna combinando frecuencia, impacto y persistencia `[PROP]`.
Espacio final: citas sobre el hijo (no anotar nombres), dudas legales o éticas, observaciones sobre el moderador.

## 8. Línea base del proceso tradicional
(i) El NASA-TLX retrospectivo de §3(a), a todos. (ii) **Tarea de control** para un subgrupo de 12, elegido por sorteo: "Ubique en una tienda en línea de papelería ya existente [URL fija] estos 8 ítems de la lista de referencia" (tarjeta con 8 ítems). Se mide tiempo y éxito; luego se aplica NASA-TLX y SEQ a esa tarea. Es una aproximación al proceso tradicional, no una recreación del recorrido por tiendas físicas.
